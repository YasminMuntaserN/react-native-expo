# 📱 React Native Projects – Course Practice

This repository contains all the projects I built while following the **[React Native - The Practical Guide](https://www.udemy.com/course/react-native-the-practical-guide/)** course by Maximilian Schwarzmüller.  
The course focuses on building **real native mobile apps** for **iOS** and **Android** using **ReactJS** and **React Native** without needing to learn Swift, Objective-C, or Java.

---

## 📚 About the Course
The course covers:
- React Native basics & advanced features
- Cross-platform app development (iOS + Android)
- Navigation, styling, and animations
- Using device features like **Google Maps** and **Camera**
- Third-party libraries
- User authentication
- Backend integration
- Publishing apps to the Play Store & App Store

We learn all of this by building **real-world apps**, including:
- 📍 Favorite Places App (maps + camera + auth)
- 🍽 Food Recipe App (navigation + data filtering)
- and more...
