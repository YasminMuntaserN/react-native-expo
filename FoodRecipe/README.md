# FoodRecipe

**Project Idea:**
A recipe app where users can browse meals by category, view details, and save favorites. Includes filtering by dietary preferences and meal complexity.

**What I Learned & Used:**
- Context API for managing favorites 
- Data-driven UI with categories and meals 
- Custom card components for meals 
- List and grid layouts
- Navigation and dynamic routing
- Responsive design and UI polish
- State management for favorites
