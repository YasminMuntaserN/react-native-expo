# ExpenseManagement

**Project Idea:**
A React Native app for tracking personal expenses. Users can add, edit, and delete expenses, view a list of recent expenses, and see the total spent in the last 7 days.

**What I Learned & Used:**
- Context API for global state management 
- File-based routing with Expo Router
- Custom forms and input validation 
- Dynamic navigation and modals
- Styling with React Native’s `StyleSheet`
- List rendering with `FlatList`
- Component reusability and separation of concerns
