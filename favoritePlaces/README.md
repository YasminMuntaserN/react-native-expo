# favoritePlaces

**Project Idea:**
An app to save and remember your favorite places. Users can add a place with a name, description, photo, and location (picked from map or current GPS), and view all saved places.

**What I Learned & Used:**
- SQLite database integration for persistent storage 
- Image and location picking with Expo modules
- Custom map view and reverse geocoding 
- Form handling and validation
- Linear gradients and advanced UI styling
- State management for form and list views
- Navigation between screens and passing parameters
